# Historie des UX-Prototyps

Die Dateien `CHANGES-UX-*.txt` dokumentieren den Entwicklungsverlauf des früheren UX-Prototyps. Sie machen insbesondere die Zeit vor Einführung des Git-Verlaufs teilweise nachvollziehbar.

Die Dateien dienen ausschließlich der historischen Dokumentation und gelten nicht als aktuelle technische Spezifikation. Für aktuelle Entscheidungen sind `PROJECT.md`, die Architecture Decision Records (ADRs) und der Git-Verlauf maßgeblich.
